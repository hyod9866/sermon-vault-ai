# Sermon Vault AI (제미나이 설교·볼트 도우미)

Google Gemini API 기반 초경량 옵시디언 설교·성경 연구 볼트 검색 및 Q&A 플러그인입니다.
**Windows, MacBook (macOS), iPad / iPhone (iPadOS / iOS)** 전 환경에서 백그라운드 인덱싱 지연 없이 즉시 작동합니다.

## 주요 기능
- **🔍 볼트 내 설교문·연구 노트 스마트 검색**: 질문 의도와 성경 사건·비유, 설교자명을 자동 파악해 볼트 내 관련 설교 노트를 찾아 답변하고 출처 링크(`[[노트제목]]`)를 연결합니다.
- **☑ 스트롱 / ☑ 주석 체크박스 연동**: 상단 검색 범위 옆 체크박스로 스트롱 원어사전(`_strong_json`) 및 주석 데이터(그랜드·호크마·매튜헨리·스펄전 등) 포함 여부를 원터치로 선택할 수 있습니다.
- **🔄 다중 API 키 자동 로테이션 & 실시간 잔량 게이지**: 여러 개의 Gemini API 키를 등록해 무료 할당량 초과 시 자동으로 다음 키로 전환하며, 하단 슬림 게이지로 일일 할당량 잔량과 토큰 여유량을 실시간 표시합니다.
- **🤖 최신 Gemini 3.5 / 3.0 / 2.5 모델 선택**: `3.5 Flash-Lite`, `3.5 Flash`, `3.0 Flash`, `2.5 Flash-Lite`, `2.5 Flash`, `2.5 Pro` 지원.

## BRAT 설치 방법
1. Obsidian에서 **BRAT** 플러그인을 엽니다.
2. **Add Beta plugin**을 클릭하고 아래 주소를 입력합니다:
   ```
   hyod9866/sermon-vault-ai
   ```
3. 플러그인 활성화 후 **설정 → Sermon Vault AI**에서 본인의 Gemini API 키를 입력합니다.
